# Данные и совместимость

Codex Activity Community — вспомогательная панель для настольного приложения. Она использует локальные файлы текущего пользователя из стандартного каталога `~/.codex` и локальный Unix-сокет Codex. SQLite открывается в режиме чтения. Панель подписывается на состояния чатов через IPC и просит снимки для синхронизации. Нажатие на карточку локального или удалённого чата открывает ссылку в Codex Desktop через macOS.

| Источник | Что доступно |
| --- | --- |
| Codex и локальный Work | Заголовок, проект, состояние, описание, время хода и расход токенов, если они есть в локальных данных |
| Удалённый Codex | Метаданные из локального каталога и живое состояние при наличии потока. При недостатке данных панель показывает «Нет статуса» |
| ChatGPT и облачный Work | Заголовок и признаки активности, которые синхронизировал Codex Desktop для текущего аккаунта. Карточки доступны для просмотра. Показ можно выключить в меню |

Панель не отправляет содержимое чатов в сеть и не собирает телеметрию. Приложение хранит свои настройки отдельно через macOS. Исходники, тесты и ZIP не содержат пользовательских баз, истории и настроек Codex.

Формат SQLite и IPC зависит от версии Codex Desktop. Если статус неизвестен, данные могут появиться после активации чата в Codex. Отчёт об ошибке лучше начать с версий macOS и Codex Desktop, источника карточки и шагов воспроизведения. Не прикладывайте переписку, базы, токены авторизации и полные логи.
