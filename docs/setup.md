# Установка Codex Activity Community

## Что нужно

- Mac с macOS 14 или новее. ZIP содержит код для Apple Silicon и Intel. Поддержка конкретного Mac также зависит от требований установленного на нём Codex Desktop.
- Codex Desktop, открытый хотя бы один раз в той же учётной записи macOS. Панель показывает данные, доступные этому настольному приложению.

## Установка из ZIP

1. Откройте [последний выпуск](https://github.com/moky-me/codex-activity/releases/latest). В разделе **Assets** скачайте файл `Codex-Activity-Community-…-universal.zip`. Файлы **Source code** предназначены для самостоятельной сборки.
2. Для проверки скачайте рядом `SHA256SUMS.txt`. В Терминале перейдите в папку со скачанными файлами и выполните `shasum -a 256 -c SHA256SUMS.txt`. Ожидаемый результат — `OK`.
3. Распакуйте ZIP и перетащите **Codex Activity Community.app** в «Программы» через Finder.
4. Откройте Codex Desktop, затем панель. У панели нет отдельной иконки в Dock. Окно можно перетащить за шапку, а двойной щелчок по шапке разворачивает его по доступной высоте экрана.

## Первый запуск

Сборка подписана локальной подписью ad hoc. Она не подписана сертификатом Developer ID и не нотариализована Apple. Если macOS блокирует запуск как приложение от неизвестного разработчика, сначала сверьте архив с контрольной суммой из выпуска. Затем после попытки открыть приложение зайдите в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск именно этого приложения. Если организация запретила это действие, согласуйте установку с администратором. [Инструкция Apple](https://support.apple.com/en-gb/102445).

Автозапуск по умолчанию включён. Если macOS попросит разрешить фоновую работу, откройте настройки входа и фоновых объектов и разрешите **Codex Activity Community Launcher**, если хотите запускать панель вместе с Codex. Состояние и переключатель доступны в меню `⋯`. Когда Codex завершается, панель закрывается.

## Проверка на новом Mac

- Запустите ход в локальном чате Codex. Карточка должна появиться в «В работе», после завершения — перейти в «Готово». Нажатие открывает тот же чат.
- Если Codex действительно ждёт ответа или разрешения, проверьте, появилась ли карточка в «Ждёт вас», пока запрос активен.
- Если список пуст, проверьте период в меню `⋯` и наличие недавнего чата в настольном приложении. Для удалённого чата откройте его в Codex, чтобы настольное приложение получило состояние. [Откуда берутся статусы](data.md).

## Обновление, откат и удаление

Для обновления скачайте следующий выпуск и замените приложение в той же папке. Сохраняйте предыдущий ZIP, если нужен откат. Публичная версия использует собственные настройки и собственный помощник.

Для удаления выключите автозапуск в меню `⋯`, закройте Codex и удалите **Codex Activity Community.app** из «Программ». При необходимости проверьте список фоновых объектов macOS.
