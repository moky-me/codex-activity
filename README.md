# Codex Activity Community

Нативная боковая панель для Codex Desktop на macOS. Показывает, какие чаты сейчас работают, где нужен ваш ответ и какие задачи завершились. Интерфейс на русском.

[Скачать для macOS](https://github.com/moky-me/codex-activity/releases/latest) · [Установка и первый запуск](docs/setup.md) · [Данные и совместимость](docs/data.md) · [Разработка и выпуск](docs/development.md)

## Что показывает панель

- Чаты Codex и локального Work за 4, 8, 12 или 24 часа. Можно выбрать период без ограничения. Чаты с подтверждённым запросом видны и за пределами периода.
- Короткая цветная отметка справа обозначает статус, а метка C, G или W рядом с проектом указывает источник. В работе подписи перебираются по списку из 68 вариантов.
- Статус, время хода и токены, когда эти данные доступны. Клик по карточке Codex или локального Work открывает чат в Codex Desktop.
- Удалённые чаты Codex, которые видит настольное приложение. Для живого статуса нужен доступный поток этого чата.
- Обычные чаты ChatGPT и облачный Work из локального каталога настольного приложения. Их можно скрыть в меню. Полнота статусов зависит от данных каталога.

## Быстрый запуск

1. Скачайте **Codex-Activity-Community-…-universal.zip** из раздела Assets и распакуйте его.
2. Перенесите **Codex Activity Community.app** в «Программы». Откройте Codex Desktop, затем панель. Она появится рядом с остальными окнами.
3. В меню `⋯` выберите период, показ токенов и облачных чатов. Автозапуск вместе с Codex можно отключить в том же меню.

ZIP содержит сборку для Apple Silicon и Intel. Минимальная версия панели — macOS 14. На целевом Mac также нужен совместимый Codex Desktop. Сборка имеет локальную подпись и не нотариализована Apple. Инструкция по проверке ZIP и первому запуску есть в [руководстве](docs/setup.md#первый-запуск).

Панель читает историю и живые статусы из локальных данных текущего пользователя. Для неё не нужны API-ключ, отдельный аккаунт или сервер. Это независимое приложение сообщества. Совместимость с новыми версиями Codex зависит от формата его локальных данных. [Что именно читает панель](docs/data.md).

## Сборка из исходников

На macOS с Swift 6, инструментами Apple и Python 3 выполните из корня репозитория:

```sh
./scripts/build.sh
swift run ActivityCoreTests
./scripts/test-panel.sh
```

Готовое приложение появится в `build/Codex Activity Community.app`. Для разработки и подготовки универсального ZIP см. [инструкцию разработчика](docs/development.md). Для агента в репозитории есть [AGENTS.md](AGENTS.md).
