# Codex Activity Community

Начните с [README](README.md), [установки](docs/setup.md) и [руководства разработчика](docs/development.md). Для работы достаточно публичного checkout. Подключать аккаунты, ключи или приватный репозиторий для сборки и тестов не нужно.

- Для изменений ядра запустите `swift run ActivityCoreTests`. Для окна, карточек и настроек — `./scripts/test-panel.sh`. Для упаковки — `./scripts/package.sh`.
- Проверяйте состояние на синтетических данных. В примеры, тесты, логи CI и публичные задачи включайте только вымышленные чаты, нейтральные пути и идентификаторы.
- Сохраняйте режим чтения локальных файлов и назначение существующих IPC-вызовов. При изменении источника данных обновите [описание совместимости](docs/data.md).
- Для обновлений из другой ветки переносите только проверенные изменения кода и тестов. Сохраняйте публичную идентичность приложения и процесс выпуска.
